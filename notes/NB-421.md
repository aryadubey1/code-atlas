# 📄 NB-421 · Import a catalog from a supplier PDF

> Demo notes. Everything here is fictional.

## 🎯 What it is

Store managers get supplier price lists as PDFs or photos. Today they retype them into the CSV template. NB-421 reads the file and shows a review grid.

```
supplier PDF ──► background job ──► draft rows ──► review grid ──► catalog
                 (reads lines)      (nothing live)   (New/Update/Fix)
```
