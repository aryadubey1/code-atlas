# 📦 NB-430 · Staff see only their own warehouses

> Demo notes. Everything here is fictional.

## 🎯 What it is

Warehouse staff only see stock in the warehouses they're assigned to. Managers get a switch to see all.

```
staff ──► assigned warehouses only
manager ──► [ show all ▢ ]
```
